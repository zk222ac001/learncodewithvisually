Optional AI Programming Tutor (private preview; public beta planned)

LearnCodeVisually provides an optional programming assistant intended for learners at different experience levels, including younger learners. Its programming tutorials and interactive visualizations remain usable without the AI Tutor. The public AI Tutor is not yet activated.

If you choose to use the AI Tutor, the browser sends your question, selected programming language, preferred response language, type of help (question, explanation, hint, debugging or review), selected explanation level, optional source code, up to six shortened recent conversation messages, and a Cloudflare Turnstile verification token to the AI Tutor Cloudflare Worker. Questions are limited to 900 characters and optional code to 2,500 characters. The Worker verifies Turnstile, applies traffic and daily usage protections, and passes relevant learning material to Cloudflare Workers AI to generate an answer. For the separate C for-loop lesson, the selected visualization step may also be supplied. The AI Tutor does not execute, compile, or test submitted code.

The Worker uses the connecting IP address for short-term rate limiting, and Cloudflare may process technical network and security information to deliver and protect these services. The application code does not deliberately write questions, code, AI answers or IP addresses to an application database. Recent conversation messages are held in the active browser page and sent only with a new question. A Cloudflare Durable Object records the UTC day and an aggregate count of reserved AI requests to enforce the shared daily limit. Cloudflare-operated logs and security systems may process information separately; their retention, access and deletion configurations must be reviewed and accurately documented by the operator before public launch.

Do not enter passwords, API keys, private student assignments, names, contact information, school identifiers, health information or other personal or confidential details. Younger learners should use appropriate non-personal examples and may seek guidance from a parent, guardian or teacher. AI-generated explanations and code can contain mistakes, so check them rather than treating the output as a verified result.

Relevant providers include Cloudflare Workers, Workers AI and Turnstile. Refer to Cloudflare Workers AI data usage information and Cloudflare's privacy policy.
