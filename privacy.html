Local learning progress

Learning preferences and progress are saved in this browser, without an account or cross-device sync. The application uses ds-language and ds-code for language choices, codeviz-progress-v1 for quiz scores, attempt counts and completion marks, codeviz-active-path-v1 for the selected learning path, and codeviz-last-lesson-v1 for the resume link. These values have no application-set expiry and remain until removed by you or your browser. Anyone using the same browser profile may see this progress. They are not sent to the AI service as part of tutor requests. Clear this site's browser data to remove them; path reset clears only the selected path's completion marks. The operator must assess the applicable storage rules for each purpose; browser-local storage is not automatically exempt from those rules.

Third-party code editors

Optional AI Programming Tutor (public beta)

LearnCodeVisually provides an optional programming assistant intended for learners at different experience levels, including younger learners. Its programming tutorials and interactive visualizations remain usable without the AI Tutor. The AI Tutor public beta is available with shared usage limits.

If you choose to use the AI Tutor, the browser sends your question, selected programming language, preferred response language, type of help (question, explanation, hint, debugging or review), selected explanation level, optional source code, up to six shortened recent conversation messages, and a Cloudflare Turnstile verification token to the AI Tutor Cloudflare Worker. Questions are limited to 900 characters and optional code to 2,500 characters. The Worker verifies Turnstile, applies traffic and daily usage protections, and passes relevant learning material to Cloudflare Workers AI to generate an answer. For the separate C for-loop lesson, the selected visualization step may also be supplied. The AI Tutor does not execute, compile, or test submitted code.

The Worker uses the connecting IP address for short-term rate limiting, and Cloudflare may process technical network and security information to deliver and protect these services. The application code does not deliberately write questions, code, AI answers or IP addresses to an application database. Recent conversation messages are held in the active browser page and sent only with a new question. Closing the tutor panel does not clear them. Clear conversation removes displayed history and drafts from this page; it does not undo completed transfers to a provider. Reloading ends the application conversation state, although your browser may independently restore form values. A Cloudflare Durable Object records the UTC day, aggregate request reservations and aggregate answered, failed and incomplete outcomes. These records contain no conversation text or visitor identifier. It presents a seven-day history; older daily summaries are removed on the next successful reservation, not by a timed deletion task. If no further request is reserved, stored summaries can remain longer. The current day-count record is replaced when a request is reserved on a new day. Cloudflare-operated logs and security systems may process information separately; their retention, access and deletion configurations remain unverified. This applies even though the public beta is enabled. The operator must complete that review; an application that does not save chat text can still have provider-level processing.

Do not enter passwords, API keys, private student assignments, names, contact information, school identifiers, health information or other personal or confidential details. Younger learners should use appropriate non-personal examples and may seek guidance from a parent, guardian or teacher. AI-generated explanations and code can contain mistakes, so check them rather than treating the output as a verified result.

Relevant providers include Cloudflare Workers, Workers AI and Turnstile. Refer to Cloudflare Workers AI data usage information and Cloudflare's privacy policy. These links are additional information and do not replace the operator's responsibility to verify actual processing arrangements and legal requirements.

Cloudflare AI and human verification

Opening the general AI Tutor starts Cloudflare Turnstile verification. The separate C for-loop tutor starts verification only after you press its verification button. Turnstile processes network and browser security signals; the Worker also sends the connecting IP address and verification token to Cloudflare's verification endpoint. This is distinct from sending a question to Workers AI. Read the Turnstile Privacy Addendum.

For standard, stateless inference, Cloudflare's Workers AI data policy says it does not use customer content for model training and does not retain inputs/outputs beyond processing and response delivery, subject to its stated exceptions. This does not promise zero retention for other Cloudflare services, security logs, or customer-enabled storage and logging.
