int main(void) {
    for (int i = 1; i <= 3; ++i) {

    }
    return 0;
}

How does a C for loop work?

The syntax is for (initialization; condition; update). Initialization runs once. Before every iteration, C evaluates the condition. If it is true, the body executes and then the update runs. When the condition is false, execution continues after the loop.

  1. Initialize: int i = 1.
  2. Check: i <= 3 before executing the body.
  3. Execute: print the current value of i.
  4. Update: ++i increments the counter by one.

Common C loop mistakes

Off-by-one errors: i < 3 prints only 1 and 2; i <= 3 includes 3. Infinite loops: if the update never makes the condition false, the loop may not finish. Zero iterations: starting with i = 4 makes the initial condition false and prints nothing.

The model above deliberately separates checking the condition from printing a value. A continue statement in a for loop still proceeds to its update expression before the next condition check.
