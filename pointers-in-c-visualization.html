Start with working C code

The pointer p stores the address of x. The expression *p accesses the object at that address; assigning to *p changes x.

#include <stdio.h>
int main(void) {
    int x = 12;
    int *p = &x;
    printf("%d\n", *p); /* 12 */
    *p = 24;
    printf("%d\n", x);  /* 24 */
    return 0;
}

What does a pointer hold?

A pointer is a value that identifies an object or function in memory. In int *p = &x;, &x obtains the address of x, and p stores that address. The type int * indicates that dereferencing p gives access to an int.

Our diagram uses the made-up address 0x1000 purely to illustrate the relationship. Real addresses are selected by the runtime environment and will vary.

The difference between & and *

&x is the address-of expression. *p is a dereference expression that accesses the pointed-to object when p is valid. In a declaration, int *p instead indicates the pointer type. These uses of the asterisk are related but appear in different grammatical contexts.

A pointer must refer to a valid, suitably typed object before you dereference it. Dereferencing a null, uninitialized or dangling pointer is invalid and can lead to undefined behavior. Always understand pointer lifetime and initialization.

Practice predicting pointer behavior

  1. After int *p = &x;, what is stored in p and what is stored in x?
  2. What does *p evaluate to before the assignment?
  3. Why does assigning *p = 24; change x?
Answers

The pointer stores the address of x; x stores the integer 12. Dereferencing p reads 12. Since p refers to x, writing through *p changes the same object to 24.
