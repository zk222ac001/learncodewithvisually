1. Read and run Python code

Python uses indentation to group statements. You can print text with print(), bind names to values with assignment, and use functions from the standard library. Unlike C, basic Python variables do not require a type declaration.

Start with Python Hello World and the variables and data types module.

2. Understand decisions

A condition controls which block runs. Python uses if, elif and else. Ask yourself what the expression evaluates to before tracing the selected branch. For instance, score >= 50 is true when the score is 50 or higher.

Explore conditional logic and comparisons interactively.

Python loop example: build a total

The code below adds the numbers 1 through 4. Python's range(1, 5) includes 1 but excludes 5. The accumulator changes after each step.

total = 0
for number in range(1, 5):
    total += number
    print(number, total)

# Output:
# 1 1
# 2 3
# 3 6
# 4 10

Trace the changing total: 0 → 1 → 3 → 6 → 10. What would happen if the range ended at 4 instead of 5? Work it out on paper, then compare your prediction with a real run.

3. Lists and indexing

A Python list stores elements in order. Indexes start at zero, so in scores = [10, 20, 30], the expression scores[1] evaluates to 20. Lists can grow or shrink, unlike fixed-size arrays in C. Visualizing positions makes indexing easier to understand.

Compare Python and C examples in the arrays lesson.

4. Functions and reusable code

Functions name a set of operations and can return a result. A Python definition starts with def. Trace the values of arguments, local names and the returned value to understand a function call.
