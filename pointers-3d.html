Why use a pointer?
A function can modify a caller’s object through its address. C still passes the pointer by value: the parameter gets a copy of the address, while both pointers refer to the same integer.
Try a prediction
Set the three values to 5, 12 and 42. Before playing, predict the printed result. Does writing through the function parameter change the original object?
Explain the answer
The output is value = 42. The function writes through its copied pointer to the same original integer. It does not create a second integer.
