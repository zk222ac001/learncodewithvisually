Try a first lesson: count passing scores

A loop visits each value; a condition decides whether that value contributes to a result. Before running this Python example, predict how many scores meet the pass mark of 50.

scores = [42, 50, 73, 49]
passed = 0
for score in scores:
    if score >= 50:
        passed += 1
print(passed)
  1. 42: the condition is false, so passed stays 0.
  2. 50: equality is included by >=, so the count becomes 1.
  3. 73: the condition is true again; the count becomes 2.
  4. 49: the condition is false. The final output is 2.

passed += 1 counts a qualifying score; it does not add the score itself. Initializing the counter before the loop keeps the result from being reset on every iteration. The final print is outside the loop, so it reports one final count.

Check your understanding: what changes with > instead of >=?

The output becomes 1: 50 no longer qualifies, leaving only 73. This is why a test exactly at the boundary is useful. With an empty list, the original program prints 0 because the loop body never runs.
